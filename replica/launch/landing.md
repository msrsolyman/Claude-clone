## Frequently Asked Questions

**Q: Do I need an Anthropic API key to use Atelier?**
A: No. Atelier includes a built-in simulation engine for local prototyping, and supports Google Gemini API keys as well as Anthropic keys. You choose which provider to power your sessions.

**Q: Is my code or prompt data sent to your servers?**
A: Never. In Community mode, all conversations, artifacts, and settings reside 100% on your local machine (`store.json` / local PostgreSQL). We collect zero analytics or telemetry.

**Q: How does the live React preview work without crashing?**
A: Atelier executes all rendered components in an isolated `<iframe>` with strict sandbox permissions. In-browser Babel compiles modern JSX on the fly, keeping your main studio interface completely secure.

**Q: Can I export my artifacts to real projects?**
A: Yes. Every artifact can be copied as raw source code or downloaded directly as `.tsx`, `.html`, or `.svg` files ready to paste into your Next.js or Vite projects.
